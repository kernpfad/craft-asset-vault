# Security Policy

## Supported versions

Only the latest released version of this plugin receives security fixes.
Older tags are unsupported once a newer stable release exists.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Prefer one of these private channels:

1. [GitHub Security Advisories](https://github.com/kernpfad/craft-asset-vault/security/advisories/new) for this repository
2. Email: support@kernpfad.dev

Include:

- Plugin version and Craft / Commerce / PHP versions
- A clear description of the impact
- Steps to reproduce or a proof of concept (if available)
- Whether the issue is already being exploited in the wild (if known)

We will acknowledge the report as soon as practical and coordinate a fix and disclosure timeline. Please give us a reasonable window to ship a patched release before public disclosure.
